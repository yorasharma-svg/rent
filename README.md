# Multi-Property Rent & Utility Management Web App (v5)

## How to Deploy on Streamlit Community Cloud (100% Free Forever)
1. Download `rent_ledger_web_app-v5.zip` and extract it.
2. Upload all files (`app.py`, `requirements.txt`, `rent_ledger.db`) to a new GitHub repository.
3. Go to https://share.streamlit.io, connect your GitHub account, select your repo and click Deploy!

## Features in v5:
- Multi-House / Multi-Property Management
- Tenant Mobile Numbers & Direct WhatsApp Click-to-Chat Link
- Dynamic Month Rollover with Auto Meter Carry-Forward
- Utility Liability & Collection Dashboard
- Previous Balance / Arrears Tracking
